# LaTeX and Overleaf template

In Overleaf, choose New Project, Upload Project, then select
`report_template_overleaf.zip`. Set `report.tex` as the main document.
The archive includes the required style and bibliography files.

Replace the example title, section text, references and group information with
your project content. Include your AI-use declaration. Section headings can
be renamed, merged or reordered to explain your investigation clearly.

The main body has a **6-page limit**. References and optional appendices are
excluded. Reviewers are not obliged to read appendices; keep essential claims,
methods and results in the main body. Keep references before the appendix.

Preserve the supplied style, margins, font size, line spacing and review mode.
Compile the report and run the PDF format checker before submission.
